# Personal

## Mi Cartera

App web para llevar el control de gastos, tarjetas de crédito y débito, compras a meses sin intereses, pagos, plan de pagos según tus ingresos y metas de ahorro, con gráficas y fotos de tickets.

Abre `mi-cartera/index.html` en el navegador. No necesita instalación: todo corre en el navegador y los datos se guardan en el `localStorage` de ese navegador (usa *Opciones → Descargar respaldo* para no perderlos).

Para tenerla en línea puedes activar GitHub Pages en este repositorio y abrir `/mi-cartera/`.
